# Website and workspace redesign

User delegates design choices. This session builds directly in code to author working product scenes and interactions from the supplied Framer references. No standing build preference is inferred.

## Direction contract
THESIS: A buyer question becomes an inspectable answer and a concrete improvement.
OWN-WORLD: Graphite surfaces, porcelain type, restrained ice-blue signals, inset physical keycaps, precise shared grid borders.
STORY: Understand AI visibility, explore a sample, test a website, create a workspace, act and recheck.
FIRST VIEWPORT: Large two-line product headline above a clear audit CTA; an interactive answer workbench spans the lower half. Quiet dotted glow surrounds the workbench.
FORM: User-pinned Framer and Aceternity craft. The design seed is subordinate to the explicit reference direction. Structured product scenes replace the previous landscape world.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Verification
Desktop and mobile homepage, auth and demo workspace. Check navigation, demo tabs, keyboard scene, walkthrough, charts, reduced motion and overflow. Real authenticated states require a valid session; a public labeled demo must never impersonate account data.

## Shipped workspace contract

+- The customer-facing loop is **status → best next action → evidence → recheck**. Empty, incomplete, and completed states each point to the next useful action.
+- The six engines remain implementation internals. Expose the work as Overview, Buyer questions, Evidence, Fix plan, and Activity.
+- The global shell gives primary weight to Home and Businesses. Billing and Settings sit with account utilities; mobile uses the same four destinations in a bottom dock.
+- Each view has one primary CTA. Secondary links may reveal detail, billing, or history without competing with the current task.
+- Prefer auditable counts, recorded answer excerpts, dates, and per-question outcomes. Do not invent a composite visibility score.
+- Activity and historical runs are supporting context, never the dashboard headline.

## Finish review

**Verdict: ship (2026-09-22).** The authenticated dashboard preserves the graphite, porcelain, and ice-blue Diagnostic Scan direction while reducing the implementation pipeline to a legible customer journey on desktop and mobile.
